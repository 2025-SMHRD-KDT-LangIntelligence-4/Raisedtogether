# 같이키움 · 같이돌봄

> **함께 아이를 돌보며 육아 부담을 나누는 공동육아 플랫폼**

## 1. 프로젝트 소개

**같이키움 · 같이돌봄**은 부모들이 서로의 육아 경험과 도움을 나누고, 함께 아이를 돌볼 수 있도록 지원하기 위해 기획한 **공동육아 플랫폼**입니다.

개별 가정이 혼자 부담해야 하는 육아의 어려움을 줄이고, 사용자 간의 연결을 통해 함께 육아할 수 있는 환경을 제공하는 것을 목표로 프로젝트를 진행했습니다.

프로젝트 기획 및 개발 과정에서 실제 서비스의 사용자 흐름을 고려하고, 웹 애플리케이션의 기본적인 구조와 기능을 구현하는 경험을 쌓는 것을 목표로 했습니다.

---

## 2. 개발 배경

육아 과정에서는 시간적·경제적 부담뿐만 아니라 아이를 돌볼 사람이 부족한 상황에서 발생하는 어려움도 존재합니다.

특히 맞벌이 가정이나 육아 지원을 받기 어려운 가정에서는 일상적인 돌봄에 대한 부담이 커질 수 있습니다.

이에 따라 부모들이 서로 연결되어 육아 정보를 공유하고, 필요한 경우 함께 아이를 돌볼 수 있는 **공동육아 플랫폼**을 기획했습니다.

**같이키움 · 같이돌봄**은 사용자 간의 연결과 협력을 통해 육아 부담을 나누는 것을 핵심 방향으로 설정했습니다.

---

## 3. 주요 기능

### 3.1 공동육아 플랫폼

사용자들이 서로 연결되어 공동으로 육아할 수 있는 서비스를 제공하는 것을 목표로 했습니다.

사용자 간의 정보 공유와 상호작용을 중심으로 서비스를 구성했습니다.

### 3.2 사용자 중심 서비스

육아를 필요로 하는 사용자가 서비스를 쉽게 이용할 수 있도록 사용자 관점에서 서비스 흐름을 구성하고 기능을 설계했습니다.

### 3.3 육아 정보 공유

사용자들이 육아와 관련된 정보를 공유하고 서로 도움을 주고받을 수 있는 플랫폼을 구성했습니다.

---

## 4. 시스템 구성

프로젝트는 사용자가 웹을 통해 서비스를 이용하고, 서버에서 사용자의 요청을 처리한 후 필요한 데이터를 데이터베이스와 연계하는 형태로 구성했습니다.

```text
┌─────────────────┐
│      사용자      │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│    Web / App    │
│   사용자 화면     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│     Server      │
│  서비스 로직 처리  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│    Database     │
│    데이터 관리    │
└─────────────────┘
```

프로젝트의 구체적인 구현 구조는 기능별 요구사항에 따라 구성했으며, 사용자 요청을 서버에서 처리하고 필요한 데이터를 저장 및 조회할 수 있도록 설계했습니다.

---

## 5. ERD

공동육아 서비스에서 필요한 데이터를 관리하기 위해 데이터베이스 구조를 설계했습니다.

사용자와 서비스에서 사용하는 데이터를 관계형 데이터베이스를 통해 관리할 수 있도록 구성했습니다.

## 7. 담당 기능

본 프로젝트의 개발 과정에 참여하여 **서비스의 기능 구현 및 개발 과정 전반을 경험**했습니다.

특히 서버와 데이터베이스를 연계하는 과정에서 백엔드 개발의 기본적인 구조를 학습하고 구현했습니다.

### Backend

* 서버 애플리케이션 개발
* 사용자 요청 처리
* 서비스 로직 구현
* 데이터베이스 연동
* SQL 작성 및 데이터 처리

### Database

* 서비스 데이터 구조 설계
* 데이터베이스 테이블 구성
* SQL을 통한 데이터 조회 및 처리

### Frontend

* 사용자 화면 구현
* 서버와 화면 간 데이터 연계
* 서비스 이용 흐름에 맞춘 화면 구성

## 8. 개발 과정에서의 경험

처음부터 완성된 구조를 가지고 개발하기보다는 프로젝트를 진행하면서 서비스의 요구사항을 분석하고 필요한 기능을 구현하는 과정을 경험했습니다.

특히 팀 프로젝트를 진행하면서 단순히 코드를 작성하는 것뿐만 아니라 **서비스의 기능을 어떻게 구성할 것인지, 데이터는 어떻게 관리할 것인지, 각 기능을 어떻게 연결할 것인지**를 고민하게 되었습니다.

이를 통해 웹 애플리케이션이 하나의 기능만으로 구성되는 것이 아니라 사용자 화면, 서버, 데이터베이스 등 여러 영역이 서로 연결되어 동작한다는 것을 이해할 수 있었습니다.

또한 프로젝트를 진행하면서 실제 개발 환경에서 발생하는 문제를 해결하고, 새로운 기술과 개발 도구를 직접 사용해보는 경험을 할 수 있었습니다.

---

## 9. 프로젝트를 통해 얻은 경험

**같이키움 · 같이돌봄** 프로젝트는 개발자로서 처음 프로젝트를 진행하며 실제 서비스의 형태를 직접 구현해본 경험이었습니다.

프로젝트를 통해 서버와 데이터베이스의 연동 과정을 이해하고, 사용자 요청이 서버를 거쳐 데이터를 처리하는 전체적인 흐름을 경험할 수 있었습니다.

또한 팀원들과 하나의 서비스를 완성해가는 과정에서 **기능 구현뿐만 아니라 요구사항 분석, 데이터 설계, 역할 분담 및 협업의 중요성**을 배울 수 있었습니다.

무엇보다 처음 접하는 기술과 개발 환경을 직접 사용하면서 발생하는 문제를 해결해 나가는 과정을 통해, 이후 개발 학습의 기반을 마련할 수 있었습니다.
